SHAHID CARROM AIM - Android Studio starter project

Build:
1. Install Android Studio on a computer.
2. Open this project folder.
3. Let Gradle sync finish.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Install the generated APK on your Android phone.
6. Open app, grant 'Display over other apps', tap Start floating aim.

Current features:
- Floating draggable panel
- Manual striker, target coin, and pocket markers
- Aim guide line and target-to-pocket direction line

Limitations:
- This is a starter/source project, not a precompiled APK.
- Manual point selection only. It does not read the game screen automatically.
- No automatic coin recognition, bank-shot physics, or guaranteed shot prediction.
- Android Studio and a computer are required to compile this project.
